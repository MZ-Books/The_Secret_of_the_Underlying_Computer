# 인터럽트

## 1. 저수준 계층의 입출력 구현 방법

1. 특정 입출력 기계 명령어 사용

      장치에 대해서도 `장치 레지스터` 가 존재하여 장치마다 고유한 주소를 부여하고 각 기계 명령어에 대한 입출력 명령어를 설계

2. 축소 명령어 집합 사용

      주소 공간 일부분을 장치에 할당하고 메모리의 읽기와 쓰기 명령어를 함께 사용

## 2. 장치 레지스터

: 각 장치들의 작업 상태를 알게 해준다.

→ 장치가 사용되지 않을 때에는 지속적으로 장치 작업 상태를 읽는다. (`polling`)

→ CPU 낭비가 심하기 때문에 동기식 방법으로 변경하여 개선 (`interrupt`)

## 3. 인터럽트

다른 명령어를 실행하던 중 새로운 이벤트가 발생하면 인터럽트 신호가 발생한다.

→ 현재 작업과 새로 발생한 이벤트 사이 우선순위를 판단하여 다음 작업을 결정한다.

이 과정에서 기존 작업의 실행 상태 저장 및 복원이 필수적이다.

```
💡 CPU가 인터럽트 신호를 감지하는 방법

: CPU가 기계명령어를 실행하는 과정에서 인터럽트 신호를 감지하는 단계 추가

```
