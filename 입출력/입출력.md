## 메모리 관점에서 입출력 = `데이터 복사`

- 입력: 외부 장치 → 메모리
- 출력: 메모리 → 외부 장치

## 출력 과정

1. 메모리에 데이터를 저장할 버퍼를 정의한 후, read 계열의 함수 호출
2. 저수준 계층에서 운영 체제에 파일 읽기 요청 → 디스크로 전달
3. 해당 프로세스 blocking이 일어나 일시중지 및 입출력 블로킹 대기열에 추가된다.
4. DMA를 통해 데이터를 특정 메모리 영역으로 복사 (buffer로 복사)
5. 입출력 작업 완료되면 준비 완료 대기열로 프로세스 이동
6. 해당 프로세스에 CPU 할당할 수 있는 상황되면 다시 해당 프로세스 재개

```
💡 무복사 기법

실제로는 파일 데이터가 프로세스 주소 공간에 직접 복사되는 것이 아니라 운영 체제 내부로 복사된 후 프로세스 주소 공간으로 복사된다.
만약, 운영 체제를 우회하여 직접 데이터를 프로세스 주소 공간에 복사하면 `무복사 기법`이 된다.
```
