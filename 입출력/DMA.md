# DMA

디스크의 입출력 처리와 CPU는 독립적으로 작용하기 때문에 병행 처리가 가능하다.

## 1. 장치 제어기

입출력 장치 = 기계 부분 + 장치 제어기(전자 부품)

장치 제어기는 장치 드라이버(운영체제에서 장치 구동을 담당)와 외부 장치(하드웨어) 사이의 연결을 담당한다.

## 2. 직접 메모리 접근(DMA)

: 메모리와 외부 장치 사이에서 데이터를 이동시키는 작업 수행

→ CPU로부터 수행해야하는 동작에 대한 상세 정보를 전달받는다

→ 장치제어기의 버퍼에서 데이터를 읽어 지정받은 메모리 주소에 데이터를 쓴다.

= 장치와 메모리 사이 데이터를 전송하는 과정에서 CPU 리소스 낭비를 막기 위해 CPU는 거의 관여하지 않는다.

- 가상 메모리 주소 개념을 지원하기 위해 운영체제로부터 가상 주소와 물리 메모리 주소 사이 매핑 정보를 제공받고
- 캐시와 메모리 사이 데이터의 일관성을 유지하기 위해 상응하는 캐시의 데이터를 즉시 메모리에 갱신한다.
- DMA가 데이터 전송을 완료하면 인터럽트를 사용하여 CPU에게 알려준다.
