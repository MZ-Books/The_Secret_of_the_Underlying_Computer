# mmap

```markdown
💡 mmap이란?

디스크의 연속된 공간에 저장된 데이터를 가상 메모리에 통째로 사상하여 마치 메모리를 읽고 쓰는 것처럼 사용할 수 있다.
```

## read/write vs mmap

- read/write 함수는 시스템 호출이나 데이터 복사로 인한 부담이 크다.
- mmap은 메모리와 파일의 사상 관계를 위한 데이터 구조가 성능에 영향을 미칠 수 있고, 페이지 누락이 발생할 수 있다.

→ 물리 메모리 용량을 초과할 정도의 큰 파일이나 동적 링크 라이브러리를 다룰 때에는 mmap을 사용한다.
